# שעשועון השין

A small iPad web app for daily practice of the Hebrew letter ש (for a child who says it closer to ס).
Each session runs about 20 minutes: a mirror warm-up, a ש/ס listening game, sentence cards with
record-and-listen and self-rating, funny voices, and drawing each sentence.

- No server and no accounts. Progress, drawings and recordings stay on the device (localStorage and IndexedDB).
- Works offline after the first visit. On iPad: open in Safari, then Share → Add to Home Screen.
- Recording and the camera mirror need HTTPS (GitHub Pages provides it).
- The sentence list is in `data.js` and can also be edited in the app's parent area (long-press "להורים").
